# Система учета спортивных результатов

Учебный проект по дисциплине
«Технологии разработки приложений на базе фреймворков».

## Описание проекта

Программа предназначена для учета спортсменов,
спортивных дисциплин, соревнований и результатов.

В практической работе №3 проект преобразован
из функциональной модели в объектно-ориентированную.

## Основные классы

### Athlete

Класс описывает спортсмена.

Атрибуты:

- id — идентификатор спортсмена;
- full_name — ФИО спортсмена;
- birth_year — год рождения.

Методы:

- __init__() — создание объекта;
- __str__() — строковое представление;
- from_data() — создание объекта из данных JSON;
- to_data() — преобразование объекта в словарь.

### Discipline

Класс описывает спортивную дисциплину.

Атрибуты:

- id — идентификатор;
- name — название дисциплины;
- unit — единица измерения результата.

Методы:

- __init__();
- __str__();
- from_data();
- to_data().

### Competition

Класс описывает соревнование.

Атрибуты:

- id — идентификатор;
- name — название соревнования;
- date — дата проведения.

Методы:

- __init__();
- __str__();
- from_data();
- to_data().

### Result

Класс описывает спортивный результат.

Атрибуты:

- id — идентификатор результата;
- athlete — объект Athlete;
- discipline — объект Discipline;
- competition — объект Competition;
- value — результат спортсмена;
- place — занятое место;
- standard — норматив.

Методы:

- __init__();
- __str__();
- check_standard() — проверка выполнения норматива;
- get_place_status() — определение статуса по месту;
- to_data() — преобразование результата в словарь.

## Взаимодействие объектов

Объект Result связывает объекты Athlete,
Discipline и Competition.

Пример:

```python
result.athlete.full_name
result.discipline.name
result.competition.name
```

В оперативной памяти программа работает со связанными
объектами. При сохранении в JSON связи записываются
через идентификаторы объектов.

## Хранение данных

Данные находятся в папке data:

- athletes.json;
- disciplines.json;
- competitions.json;
- results.json.

При загрузке данные JSON преобразуются в объекты классов.
При сохранении объекты преобразуются обратно в словари.

## Реализованная функциональность

Программа позволяет:

- просматривать и добавлять спортсменов;
- просматривать и добавлять дисциплины;
- просматривать и добавлять соревнования;

- определять статус по занятому месту.
