# Система учета спортивных результатов

## Назначение

Приложение предназначено для учета спортивных результатов участников соревнований.

Система позволяет хранить информацию о спортсмене, спортивной дисциплине, соревновании и полученном результате.

## Целевая аудитория

Спортсмены, тренеры и организаторы спортивных соревнований.

## Предметная область

Предметной областью проекта является учет результатов спортивных соревнований.

Для каждого спортсмена учитывается дисциплина, соревнование, полученный результат и занятое место.

## Основные сущности

- Спортсмен — участник спортивного соревнования.
- Дисциплина — вид спортивного соревнования.
- Результат — показатель, полученный спортсменом.
- Соревнование — мероприятие, в котором принимает участие спортсмен.

## Основные функции

- проверка корректности введенного результата;
- определение статуса спортсмена по занятому месту;
- проверка выполнения спортивного норматива.

## План развития

На следующих этапах планируется:

- добавление нескольких спортсменов и результатов;
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
