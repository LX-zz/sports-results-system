# Система учета спортивных результатов

Консольное приложение для учета спортсменов и результатов соревнований.

## Предметная область

Система предназначена для хранения информации о спортсменах,
спортивных дисциплинах, соревнованиях и результатах.

## Основные сущности

- спортсмен;
- дисциплина;
- соревнование;
- результат.

## Возможности

- просмотр спортсменов;
- добавление спортсменов;
- поиск спортсменов;
- просмотр результатов;
- добавление результатов;
- поиск результатов;
- удаление результатов;
- проверка выполнения норматива;
- определение медали;
- сортировка результатов;
- получение статистики;
- хранение информации в JSON.

## Структура проекта

- main.py — главное меню;
- athletes.py — работа со спортсменами;
- results.py — работа с результатами;
- storage.py — загрузка и сохранение JSON;
- utils.py — безопасный ввод;
- data/ — файлы данных;
- tests/ — тесты pytest.
