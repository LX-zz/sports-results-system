# Система учета спортивных результатов

Учебный проект по дисциплине
«Технологии разработки приложений на базе фреймворков».

## Описание проекта

Проект предназначен для учета спортсменов,
спортивных дисциплин, соревнований и спортивных результатов.

Проект развивается поэтапно:

- в ПР3 реализована объектно-ориентированная модель;
- в ПР5 добавлен веб-интерфейс на Django.

Консольная версия проекта сохранена.
Веб-интерфейс использует ту же предметную область
и данные из JSON-файлов.

## Используемые технологии

- Python 3.13;
- Django 5.2;
- HTML;
- CSS;
- Bootstrap 5;
- JSON;
- pytest;
- flake8;
- Git.

## Основные классы

### Athlete

Класс описывает спортсмена.

Атрибуты:

- id — идентификатор спортсмена;
- full_name — ФИО спортсмена;
- birth_year — год рождения.

Методы:

- __init__() — создание объекта;
- __str__() — строковое представление;
- from_data() — создание объекта из данных JSON;
- to_data() — преобразование объекта в словарь.

### Discipline

Класс описывает спортивную дисциплину.

Атрибуты:

- id — идентификатор;
- name — название дисциплины;
- unit — единица измерения результата.

Методы:

- __init__();
- __str__();
- from_data();
- to_data().

### Competition

Класс описывает соревнование.

Атрибуты:

- id — идентификатор;
- name — название соревнования;
- date — дата проведения.

Методы:

- __init__();
- __str__();
- from_data();
- to_data().

### Result

Класс описывает спортивный результат.

Атрибуты:

- id — идентификатор результата;
- athlete — объект Athlete;
- discipline — объект Discipline;
- competition — объект Competition;
- value — результат спортсмена;
- place — занятое место;
- standard — норматив.

Методы:

- __init__();
- __str__();
- check_standard() — проверка выполнения норматива;
- get_place_status() — определение статуса по месту;
- to_data() — преобразование результата в словарь.

## Django-проект

В ПР5 создан Django-проект `sports_site`.

Созданы Django-приложения:

- `homepage`;
- `sports`.

Приложение `homepage` отвечает за:

- главную страницу;
- общую навигацию;

Приложение `sports` отвечает за:

## URL-маршруты

Реализованы следующие страницы:

- `/` — главная страница;

- `/results/` — список результатов;
- `/results/<id>/` — страница результата;
- `/competitions/` — список соревнований.
